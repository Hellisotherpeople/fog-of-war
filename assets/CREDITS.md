# Assets

- `DejaVuSansMono.ttf`, `DejaVuSansMono-Bold.ttf`: the DejaVu fonts, free under the Bitstream Vera /
  Arev licences (see `DejaVu-LICENSE.txt`).
- `terminal*.png`, `dejavu16x16_gs_tc.png`: CP437 bitmap font sheets from the
  [libtcod](https://github.com/libtcod/libtcod) project's `data/fonts` (BSD 3-Clause, see libtcod's
  `LICENSE.txt`). The game uses `terminal10x16_gs_ro.png` when the bitmap font is selected (F4).

Everything else you see and hear - terrain, soldiers, vehicles, ships, aircraft, gunfire, engines, the
distant battle - is painted or synthesised by the code at start-up.
